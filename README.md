# UNICEF Supply Division prototype (GoCarbonTracker)

Static React + Vite app exported from `apps/public-sector` in GoCarbonTracker/go-carbon-insights at `50cc9caf6`.
Pages: `/` index, `/suppliers`, `/map`, `/climate`, `/segments`, `/hypergraph`. Data is the prebuilt JSON in `buyers/unicef/`; `scripts/` rebuilds it only inside the main repo, where the knowledge bases live.

`npm install && npm run dev` · `npm test` · `npm run build`
